# Jogo da Onça 3D

**Jogue:** https://lorenzoortizsoares.github.io/jogo-da-onca/

O Jogo da Onça é um jogo de tabuleiro tradicional de povos indígenas do Brasil: uma onça
contra 14 cachorros. A onça vence capturando 5 cachorros; os cachorros vencem quando
deixam a onça sem movimentos.

- Tabuleiro 3D em visão isométrica, com bonequinhos de madeira (vira-latas caramelo e uma suçuarana).
- Contra o computador (Básico, Intermediário, Avançado, Expert) ou 2 jogadores no mesmo aparelho.
- Feito primeiro para celular.

## Para quem mexe no código
- `index.html` é gerado: edite `codigo/` e rode `ferramentas\montar.ps1`.
- Testes: `testes\rodar-testes.cmd` (regras/computador e tela/3D, no celular e no computador).
- Toda falha encontrada vira um teste: `testes/REGRESSOES.md`.
- Especificação: `docs/especificacao.md`.

Grafismos inspirados na arte indígena amazônica (padrões geométricos genéricos).
